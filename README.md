# AI RevOps Auditor

AI-powered RevOps auditing platform for Marketing, Sales and Revenue teams.

## Features

- Funnel Analysis
- CAC Calculation
- LTV Calculation
- Payback Period
- Conversion Rate Analysis
- Revenue Leakage Detection
- Executive PDF Reports

## Data Sources

- HubSpot
- Salesforce
- Google Analytics 4

## KPIs

- CAC
- LTV
- MQL → SQL Conversion
- SQL → Opportunity Conversion
- Opportunity → Won Conversion
- Payback Period
- Revenue per Customer
